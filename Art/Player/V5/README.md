# 叠页旅人 V5：十六帧与坡面

沿用用户选定的 C 方案：长发、暖白叠页衣、灰梅内衬、植物印纹与朱砂围巾。身体来自 **AI 生成手绘风位图**，并非人工逐帧绘制。围巾保持独立布条。V4 和共享控制器均保留。

## 入口

- 角色：`res://Component/Player/V5/Traveler_V5.tscn`。
- 观察场：`res://Art/Player/V5/Traveler_V5_Lab.tscn`，F6；平地走/跑、上坡 18°、下坡 28°及转身。
- 检查：`res://Art/Player/V5/Traveler_V5_Check.tscn`。
- 实录：`Exports/Traveler_V5_Lab.mp4`，8 秒、60fps、1280×720。

## 原图与锚点

`Generated/Walk_16.png`、`Run_16.png` 均为 1254×1254 RGBA，名义 4×4 格网，各 16 张不同候选图片。它们未形成可信的完整步态周期，不能将不同图片数量当作连续动作相位数量。待机、跳跃、落地与刹停的 8 张图沿用 V4 `Traveler_C_Actions.png`，总计 40 张。生成提示词与来源保留在 `Generated/`。

部分脚部跨越名义格线，因此 `Traveler_V5_Layout.json` 使用逐格真实区域裁切，原 PNG 不改写。步行全图统一 0.326、奔跑全图统一 0.34、旧动作全图统一 0.2；不逐帧拉伸人物。站立约 95px。根点校准接触地面，腾空姿态保留离地高度。`order` 根据可见腿姿重排原图，原图全部保留；16 个像素哈希不同仅验证没有复制旧帧充数，不能证明动画质量。

构建：先导入母图，再运行 `Build_Traveler_V5.gd`。输出 `Traveler_V5_Frames.tres` 与 `Traveler_V5_Metadata.json`，记录图集来源、裁切区域、统一缩放、根点、领口和可见脚点。

## 动作与坡面

步速 180、跑速 320、短冲 560px/s，实体 30×86，跳速 610，保持 V4 玩法参数。V5 使用独立跨步控制器，场景局部设置 `floor_snap_length=8`、`floor_constant_speed=true`；共享控制器不变。步态按照碰撞完成后的坡面切向真实行程推进，走/跑周期仍为 108/152px。顶墙不空踏。起步选择较窄的候选图片，走跑在固定周期窗口换组并共享相位；因原图周期不完整，该窗口不能保证正确的接触姿态。没有混叠两套肢体制造残影。

原图映射到 14×30 网格，只有下腿区域作有限地形适配。查询只检查玩家当前碰撞掩码，排除自身；在悬空边缘没有地面命中时不吸附。角色整体保持竖直，上身使用不超过约 3° 的小幅剪切倾身，重心平滑贴近中心地面。换图后立即校正新脚位，避免沿用上一张图的高度短暂穿坡。跑步腾空和摆动脚保留原图离地量，跳起后退出贴地。

围巾长 74、宽 7px，沿用已受长度/弯曲约束的 V4 独立副本。所有物理节点变换只在物理帧更新；显示帧仅调整着色器插值和请求布条重绘。

## 已知限制

2026-10-09：默认 60Hz 物理下检查场 114 项、0 失败，包含坡顶接平地再下坡无意外弹起与台阶边缘空脚查询。实际 GPU 观察场运行 480 帧，无脚本或渲染错误；MP4 首、中、末帧可解码。该结果验证功能和接入，不替代用户对动作自然度的审阅。

AI 母图仍有相似相位、手臂配合和衣摆轮廓跳变。当前是可玩候选，不把“16 帧”描述为专业动画验收通过；若试玩仍觉得机械，下一步应对已选腿姿补绘真正中间姿态与修订时间间隔，而非继续凑 30 张近似图片。脚底地形匹配也不等于横向支撑脚已连续锁定；本轮未增加逐帧关节重画或整人旋转。

## 同日反馈后的修正

真实缓坡追踪未发现反复起步重置；相位连续时仍有明显外观回跳，原因包括近似长跨图片连排、突然收腿、摆臂冻结与缺失近远腿交换。`Playback_Order_Review.tscn` 可直接查看实际播放顺序，重新排序无法补齐这些缺失动作。

播放器另修复了可重现的单帧接触变化误插播fall/land：起停改用输入和实际行程语义，短失地保留最多50ms地面动作，真正起跳立即离地；接入局部跨步高度的身体缓释。`Slope_Gait_Regression.tscn` 42项通过，详见 [坡面步态诊断](../../../ProjectLogs/坡面步态修复_2026-10-09.md)。功能通过仍不表示原AI图片已经具备合格动画连续性。
