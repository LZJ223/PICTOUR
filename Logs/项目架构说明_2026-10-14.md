# PICTOUR 项目架构说明

> 初始文档日期：2026-10-14
> 最后更新：2026-10-15
> Godot 版本：4.7.2-stable
> 本文描述组件精简后的当前代码，不以历史开发日志中的旧实现为准。

## 1. 项目概览

PICTOUR 是一个 2.5D 平台跳跃与景深换层原型。当前实现围绕三种状态分离展开：

- 物体根节点与 `CollisionBox` 保存真实位置、真实尺寸和物理碰撞；
- `DepthLayer.slot` 表示画面中的景深位置；
- `VisualRoot` 根据槽位与相机锚点计算显示缩放和视差，不反向覆盖物理状态。

当前主场景为 `Prototype_Game.tscn`，主关卡为 `Level/Prototype_Level.tscn`。项目保留的核心能力包括：

- 四层景深槽位循环；
- 玩家移动、跳跃与无人机切换；
- 鼠标选择景深物体；
- 单个物体跨层转换；
- 物体换层成功缩放反馈与失败抖动反馈；
- 图层级模糊、压暗、偏色和对比度衰减；
- 选择外描边；
- 跨层影子投影和多边形布尔切割。

已从当前工程移除的旧组件包括风扇、目标物、拾取物、移动/弹力平台、通用触发器、藤蔓和第一关白模。与它们绑定的风力、拾取账本、对话、检查点、死亡恢复、机关调用、藤蔓状态和弹跳处理也已经从公共脚本中清除。

## 2. 运行时结构

```text
Prototype_Game.tscn
├─ Level                         # Prototype_Level.tscn
│  ├─ Layer3 : DepthLayer
│  ├─ Layer2 : DepthLayer
│  ├─ Layer1 : DepthLayer
│  │  ├─ House : StaticBox
│  │  └─ House2 : StaticBox（树木场景实例）
│  └─ Layer0 : DepthLayer
├─ Player : PlayerController
├─ Camera : Camera2D
├─ LayerControllerSystem
└─ ShadowControllerSystem
```

每个 `DepthLayer` 都是一个带独立 `ShaderMaterial` 的 `CanvasGroup`，并从 `Depth_Layer.tscn` 继承默认地面。

## 3. 自动加载

| 名称 | 文件 | 职责 |
|---|---|---|
| `Global` | `System_Script/Global.gd` | 保存图层配置、主场景节点引用和当前选中物体 |
| `SignalSystem` | `System_Script/Signal.gd` | 读取全局输入、发出图层/UAV/影子信号、执行鼠标点选 |
| `Renderer` | `System_Script/Renderer.gd` | 保存画面参数并写入全局 Shader uniform |

## 5. 脚本详细说明

### 5.1 `Global.gd`

`Global` 是最小化后的运行时上下文，保存：

- `layer_count`、`layer_scales` 和 `current_layer_index`；
- `player`、`camera`、`level` 和 `layers`；
- `object_selected` 和 `camera_fixed`。

`discover_scene_nodes()` 从主场景递归发现玩家、相机和关卡，然后：

1. 调用 `Level.write_to_global()` 写入图层参数，并把本关前后景偏移色写入 `Renderer`；
2. 收集根关卡下的全部 `DepthLayer`；
3. 检查槽位是否唯一、数量是否匹配；
4. 初始化相机与玩家碰撞组。

`get_layer_at_slot()` 是系统查询视觉槽位对应物理图层的统一入口。

### 5.2 `Signal.gd`

对外信号：

| 信号 | 用途 |
|---|---|
| `layer_cycle(direction, check_collision)` | 请求轮换全部图层 |
| `layer_change(direction, object)` | 请求移动一个选中物体 |
| `UAV_activate()` | 请求切换玩家形态 |
| `shadow_boolean()` | 请求执行一次影子布尔运算 |

Q/E 会根据 `Global.object_selected` 自动分流：没有选中物体时轮换图层，已有选中物体时转换该物体。

鼠标左键通过 `PhysicsPointQueryParameters2D` 查询点选 `Area2D`，向父级寻找 `LayerObject`，并按所属层的 Z 值选择最前对象。

脚本中的两秒单次计时器用于等待画面和物理稳定。超时后暂停 `PhysicsServer2D` 并触发影子布尔；玩家移动、图层输入或点选会调用 `timer_reset()` 重新启用物理并重启计时。

### 5.3 `Renderer.gd`

保存前后景模糊步进、最大模糊 LOD、前景压暗、偏色强度、对比度衰减及描边参数。前后景偏移色由当前 `Level` 初始化写入；`apply_settings()` 再把全部参数同步到 `project.godot` 注册的全局 Shader uniform。

### 5.4 `Layer_Controller_System.gd`

该脚本是图层机制协调器：

- `_process()` 让相机跟随玩家，并刷新每个 `DepthLayer`；
- `cycle()` 检查玩家进入目标物理层是否碰撞，然后循环移动全部槽位；
- `transfer()` 计算单物体换层后的真实位置、尺寸和碰撞；
- `_has_collision()` 将凹多边形拆成凸多边形后查询目标物理层；

### 5.5 `Shadow_Controller_System.gd`

收到 `shadow_boolean` 后，系统按从后向前的顺序：

1. 收集各投影物体在目标层上的世界多边形；
2. 找到 `can_be_shadowed` 的目标物体；
3. 使用 `Geometry2D.clip_polygons()` 逐次做差集；
4. 过滤面积过小或无法用单个 `CollisionPolygon2D` 表示的结果；
5. 从原场景实例化碎片，写入碰撞、视觉与点选多边形；
6. 成功生成碎片后删除原物体。

### 5.6 `Depth_Layer.gd`

`layer_id` 是固定物理层编号，`slot` 是可循环的视觉景深位置。`apply_slot_state()` 根据两者刷新：

- CanvasGroup 的 Z 排序：关卡层为 `0`，每向前一层 `+100`，每向后一层 `-100`；
- 非关卡层的 mipmap 开关，为前后景 LOD 模糊提供采样；
- 将相同的 `z_index` 作为 `layer_z_index` 直接传入图层滤镜；
- 直属 `LayerObject` 的画面缩放与视差。

### 5.7 `Layer_Object.gd`

`Layer_Object.gd` 可以直接挂载到普通物体场景；只有确实需要额外行为时才创建子类。所有景深物体必须提供：

```text
LayerObject : PhysicsBody2D
├─ CollisionBox : CollisionPolygon2D
└─ VisualRoot : Node2D
   ├─ Polygon2D / Sprite2D
   └─ Area2D（需要点选时）
```

主要职责：

- `transfer_to()`：重挂到目标 `DepthLayer` 并应用真实变换；
- `apply_visual_transfer()`：计算基础视差并叠加换层动效；
- `update_layer_slot()`：同步当前物理碰撞层，并在不脱离 `CanvasGroup` 滤镜的前提下，根据 `front` 调整同 Z 兄弟节点的绘制顺序；
- `play_transfer_success()`：向外先放大、向内先缩小，随后回到正常画面尺寸；
- `play_transfer_blocked()`：用衰减水平位移表达换层受阻；
- `_setup_selection_outlines()`：递归为 `Polygon2D` 和 `Sprite2D` 创建描边副本；
- `_sync_selection_outlines()`：同步几何、贴图帧、UV、Z 值和缩放补偿。

### 5.8 `Shadowed_Geometry.gd`

该类覆盖 `_ready()`、`apply_visual_transfer()` 和 `update_layer_slot()`：

- 为每个可能的后方目标槽位复制投影轮廓；
- 按投射物、目标槽位和相机锚点计算投影位置与缩放；
- 仅在投射物位于关卡层之后、目标承影层之前时显示投影。

### 5.9 `Player_Controller.gd`

状态机目前只有：

| 状态 | 行为 |
|---|---|
| `NORMAL` | 左右移动、重力和跳跃 |
| `UAV` | 四方向自由移动，并受离原身体最大距离限制 |

进入 UAV 时，普通身体被隐藏并在当前关卡槽位对应的 `DepthLayer` 中生成 `Player_Object`。退出时，系统轮换图层直到该本体回到当前槽位，然后恢复玩家位置、缩放和普通形态。

## 6. 核心系统路径

### 6.1 启动

```text
Prototype_Game.tscn
└─ LayerControllerSystem._ready()
   ├─ Global.discover_scene_nodes()
   ├─ Renderer.apply_settings()
   ├─ 连接 SignalSystem.layer_cycle
   └─ 连接 SignalSystem.layer_change
```

### 6.2 整体图层轮换

```text
Q / E（没有选中物体）
└─ SignalSystem.layer_cycle
   └─ LayerControllerSystem.cycle()
      ├─ 预测玩家目标层
      ├─ 检查目标层碰撞
      ├─ 切换玩家 collision layer/mask
      ├─ 循环更新所有 DepthLayer.slot
      └─ 刷新直属 LayerObject 的碰撞层
```

### 6.3 单物体换层与反馈

```text
鼠标左键选择物体
└─ Q / E
   └─ SignalSystem.layer_change
      └─ LayerControllerSystem.transfer()
         ├─ 验证 can_transfer、目标槽位和目标层
         ├─ 以相机为锚点换算真实位置
         ├─ 按槽位倍率比缩放真实碰撞体
         ├─ 检查目标层碰撞
         ├─ 失败：play_transfer_blocked()
         └─ 成功：transfer_to() → play_transfer_success()
```

成功动画只修改 `VisualRoot` 的附加倍率，不延迟或修改已经完成的真实换层。快速连续操作会先终止旧 Tween 并清除残余缩放/偏移。

### 6.4 视差与图层后处理

```text
LayerControllerSystem._process()
├─ Camera 跟随 Player
└─ DepthLayer.apply_slot_state(camera_position)
   ├─ 更新图层 Z 与 Layer_Depth_Filter
   └─ LayerObject.apply_visual_transfer(anchor)
      ├─ VisualRoot.scale = CollisionBox.scale × 槽位倍率 × 动效倍率
      └─ VisualRoot.position = 视差位置 + 动效偏移
```

### 6.5 选择描边

```text
SignalSystem 点查询
└─ LayerObject.set_pick_condition(true)
   └─ 显示运行时描边副本
      └─ Selection_Outline.gdshader
```

### 6.6 UAV

```text
Page Up
└─ SignalSystem.UAV_activate
   └─ PlayerController.UAV_activate()
      ├─ NORMAL → UAV：生成 Player_Object.tscn，切换碰撞与视觉
      └─ UAV → NORMAL：对齐本体槽位，恢复位置与缩放，删除临时本体
```

### 6.7 影子布尔

```text
系统空闲两秒
└─ SignalSystem.shadow_boolean
   └─ ShadowControllerSystem.shadow_boolean()
      ├─ 收集 shadow_box 世界多边形
      ├─ 对 can_be_shadowed 物体做差集
      └─ 生成碎片并替换原物体
```

## 8. 场景约定

### 8.1 新关卡

1. 根节点挂载 `Level.gd`；
2. 根节点直属 `DepthLayer` 数量必须等于 `layer_count`；
3. 每个 `layer_id` 和初始 `slot` 必须唯一；
4. 普通景深物体直接放在对应 `DepthLayer` 下；
5. 每个图层使用独立本地 `ShaderMaterial`；
6. 主场景提供 `PlayerController`、`Camera2D`、`LayerControllerSystem` 和需要的影子系统。

### 8.2 新景深物体

1. 根节点必须继承某种 `PhysicsBody2D`；
2. 普通物体直接挂载 `Layer_Object.gd`，需要扩展行为时再继承 `LayerObject`；
3. 提供名为 `CollisionBox` 的 `CollisionPolygon2D`；
4. 提供名为 `VisualRoot` 的 `Node2D`；
5. 需要点选时在 `VisualRoot` 内提供带碰撞形状的 `Area2D`；
6. 用根节点设置关卡位置，用 `CollisionBox.scale` 表示真实尺寸；
7. 不使用 `VisualRoot` 的基础 Transform 摆放关卡，它由视差系统管理；
8. 需要额外碰撞区域时，覆盖 `update_layer_slot()` 并先调用 `super()`。

## 9. 当前边界

- `Box.tscn`、`Static_Box.tscn` 和 `Shadowed_Geometry.tscn` 是保留模板，其中只有小屋和树木实例进入当前原型关卡；
- 影子布尔要求碎片场景具备特定的多边形节点结构，暂不支持任意 Sprite 场景切割；
- 布尔碎片目前只复制白模颜色，不复制贴图 UV 或复杂材质；
- 影子空闲流程会暂停全局 2D 物理，下一次活动通过 `timer_reset()` 恢复；
- 项目尚无正式关卡完成、存档、对话、拾取、重生、音频或完整 UI 系统；
- `Project_Logs` 中的旧日志保留历史实现描述，不能作为当前 API 清单使用。

## 10. 后续表现层扩展入口

- `SignalSystem.layer_cycle` / `layer_change`：操作预提示与输入反馈；
- `LayerControllerSystem.cycle()` / `transfer()`：整层和单物体过渡；
- `DepthLayer.apply_slot_state()`：连续景深插值；
- `LayerObject.play_transfer_success()` / `play_transfer_blocked()`：换层缩放、抖动、残影和音效；
- `LayerObject.set_pick_condition()`：悬停与选中反馈；
- `PlayerController.UAV_activate()`：形态切换和镜头反馈；
- `ShadowControllerSystem` 完成切割的位置：碎裂、溶解与尘埃效果。

表现逻辑应优先修改 `VisualRoot`、Shader 参数、动画和音效，不直接覆盖 `CollisionBox`、`owner_layer`、`layer_id` 或 `slot` 的核心状态。
