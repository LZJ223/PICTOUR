# 独立步态灰稿实验

F6入口：`Motion_Study.tscn`。独立展示180px/s步行和320px/s奔跑，不替换F5、不生成PNG图集、不修改C方案角色。画面是代码原生的动作结构灰稿，不能当作最终人物美术或完整动画方案已获认可。

近腿/远腿身份固定。支撑段脚点锁在假定平地的世界坐标；摆动段使用端点位置与速度连续的曲线。髋和手臂使用循环关键值插值，膝关节由两段定长结构求解。跑步有两个短暂双脚离地窗口；60Hz更新结构，显示帧插值绘制。

实录：`Exports/Motion_Study.mp4`，8秒、60fps、1280×720。D3D12实际480帧无脚本或渲染错误；平地支撑点滑动测量为0px，循环位置接缝误差小于0.00003px，步行没有双脚离地，奔跑检测到双脚离地。

这些数字验证的是自定平地约束与循环计算。**尚未连接真实CharacterBody2D、地形、转向、加减速、跳跃或纸墨材质**，也不证明姿态已经自然讨喜。用途仅为审阅“先把动作结构做连续，再接分件美术”的路线。
