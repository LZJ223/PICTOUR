## 动作约束

平地行程周期为走90px、跑124px，坡度越大越缩短；相位来自真实坡面位移。腿段各28px，支撑期保留世界脚点，摆动期先离地加速，再收脚，着地减速。跑步有短双脚离地相位；近远腿不会通过换图伪造交换。

整体倾身约0.15–1.4°；平地重心实测变化1.68px。手臂低位反向小幅摆动，衣摆和后发有延迟；58px、3.6px宽的独立围巾保持长度约束，末段重力带来曲率与松弛。显示帧仅插值网格和布条，不写角色物理变换。

坡面脚点只查询玩家当前碰撞mask，并排除自身。陡坡会缩短支撑跨度，摆脚提跟保持骨长可达；实际支撑脚不通过缩放腿部来触地。±28°走动的骨盆适应变化可达约6px，不能把平地1.68px结论用于所有地形。

连续步行的小台沿／短暂失地不重新起步；走跑过渡预测剩余行程的落脚位置，避免周期长度改变造成足点跳变。真正起跳后用0.14秒过渡收腿，随后随上升／下落缓慢变化。停步收拢使用平滑权重，静止后脚点与相位保持不动。

`Visual_Body/Traveler.reset_after_restore()` 用恢复位置与朝向清理世界脚锚、相位、旧姿态、衣发惯性；围巾由调用方单独执行 `Visual_Body/Scarf.reset_cloth()`。这一接口供小距离撤回使用，不依赖“超过100px才判传送”。

## 本轮验证与边界

专项覆盖0/±3/±18/±28度，双向真实走／跑、骨长、支撑点、相位、走跑转换、8px台沿、受控1帧失地、停步、满跳和围巾长度；164项通过。受控失地是故障注入，不代表普通场景必然丢地。GPU观察场录制无引擎错误；MP4首、中、末帧可解码。

尚未制作独立冲刺姿态、复杂攀爬或表情。冲刺仍采用加速的连续跑步结构；陡峭／复杂落脚组合需要新关卡中的实际试玩，不能以平面坡道测试替代。公共控制器的逻辑与参数未因目录整理改变。V6保留于Story庭园和独立Vertical试验；当前F5为V7绘本箱庭，具体入口见项目README。
