# 开屏动画

项目入口为 `Opening.tscn`。仅正常启动游戏时播放；`SceneTransition.enter_main_menu()` 仍直接进入 `Interface/Main.tscn`，关卡返回菜单不会重播。

## 动画与加载

1. 轻量入口只引用 `Texture/Logo/Logo.png`、由其提取的轮廓数据、一份合成着色器和 `Texture/Logo/Godot.png`。
2. 深灰底上按路径依次画出上、下两段外轮廓，不连接独立轮廓，也不描内部颜色分界。以 1080p 设计尺寸向内描边约 8px，外缘由原图 Alpha 裁切。
3. 完整轮廓保留，内部以轻微波动的水面自下而上填成白色剪影。上述动画期间同时用 `ResourceLoader` 后台加载 Main 和主菜单音乐（仅缓存，不播放）。填满后的停留期间等待资源并初始化 Main，等背景实际绘制后再揭示；较慢设备可在此阶段多停留。
4. Logo 独立圆形蒙版先揭示原色，同时快速放大、回落；背景圆形蒙版默认延迟 0.2 秒，再展开模糊动态背景，二者不再共用进度。Back UI 提前随背景揭示，并由 CanvasLayer 固定在屏幕右上角，镜头往返不改变其位置；回正后恢复普通菜单控制，不重新显示或移动 Back。
5. 背景停留后镜头垂直上移，在天空展示重绘的 Godot 图标。此时准备完整菜单：按存档显示七个字母，显示背景机器人和菜单，并停用开屏完整彩色 Logo 的覆盖绘制。随后垂直下移时直接展示这份实际菜单并解除额外模糊；回正后只解除输入锁，不再切换 Logo 或淡入机器人、菜单。背景从入树起一直滚动，镜头往返期间也不暂停。
6. Main 作为根节点下的同一实例继续运行；开屏覆盖层销毁，背景的滚动进度不重置。菜单音乐此时才开始。

入口原生 Boot Splash 使用同色深灰背景、不显示 Godot 默认图片。引擎和 Autoload 初始化仍先于场景动画；后台加载也不保证节点初始化完全没有主线程开销。

## 调整方式

在 `Opening.tscn` 根节点 Inspector 中调整：

- `Logo`：设计画布上的宽度、向内描边宽度、涨水波幅、放大倍率、冲出／回落时长。描边、白色与原色版本共用纹理坐标和矩形，保持透明边缘与位置严格一致。
- `Overlay/GodotLogo` 节点：直接显示重绘 PNG（已包含文字，不再叠加标题）。可以在场景中调整 Texture 和尺寸，运行时保持居中与等比缩放。
- `镜头与模糊`：背景初始滚动偏移、开场镜头 Y 偏移、抬头高度（屏幕数）、背景模糊 LOD。偏右取景只设置背景初始相位，不产生横向镜头运动；远景 CanvasLayer 会同步竖直镜头位移。
- `节奏（秒）`：描边、涨水、Logo 显色、背景揭示延迟和其他阶段的停留与运动时间。Logo 圆形扩张和冲出同时开始，背景揭示稍后启动。

以 1920×1080 为设计基准，游戏和 Godot 图标保持等比缩放；圆形遮罩按屏幕像素距离计算，非 16:9 窗口中也保持圆形。背景覆盖整个窗口。

Esc、空格或用户绑定的返回键可以跳过；若 Main 尚未准备好，会等待完成初始化后再直接交接。没有使用 AI 或新增绘制美术素材。

## 重新生成轮廓

`Logo_Stroke.png` 是数据纹理，不是新绘制的美术：RG 编码沿轮廓的 16 位累计弧长进度，B 编码距轮廓的距离（范围 64 个原图像素），A 表示有效距离带。运行时仅采样，不提取轮廓。务必保持无损压缩、关闭 mipmap 和 Alpha 边缘修复，着色器中不使用 `source_color`。

替换 `Texture/Logo/Logo.png` 后，在项目根目录运行：

```powershell
godot --headless --path . --script res://Opening/Bake_Logo_Stroke.gd
```

然后让编辑器重新导入图片。该脚本只负责离线生成素材，不参与开屏加载。

## 回归与预览

运行 `Opening/Tests/Opening_Test.tscn`。自动检查资源迁移、描边／涨水阶段、独立蒙版的时序、同实例背景、天空 Godot 图标、输入锁、菜单交接、关卡返回不重播和加载期间跳过。真实渲染模式额外验证涨水时下半部已填白、上半部尚未填白，并将阶段截图写入 `.godot/opening_qa/`，可用 `--resolution 1920x1080` 生成 1080p 预览。

测试环境说明：当前 Godot 4.7.2 进程退出时仍会报告资源回收警告。直接运行原 Main 可复现 OggVorbis 相关警告；仅异步加载 Main 的最小用例也可复现 RefCounted 退出警告。开屏节点清理、输入解锁和同实例交接由回归测试单独验证，本次未扩展修改引擎或音乐系统。
