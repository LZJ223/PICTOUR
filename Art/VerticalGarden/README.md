# 折页井母素材

本轮沿已认可的 `Art/Concepts/Paper_Garden_01.png` 制作两个新的场景母素材，供独立纵向空间试验使用。原图完整保留；游戏通过 Godot 的纹理区域和网格使用原像素，没有改写 PNG。

| 母素材 | 形态与用途 | 原始记录 |
|---|---|---|
| `Generated/Curled_Root_Gate.png` | 非对称卷根、天然断肩、右侧空腔；断肩提供逐段落脚，根腹影响下方通行 | 同名 `.prompt.txt` 和 `.source.json` |
| `Generated/Hanging_Bough_Bridge.png` | 弧形枝背、下垂根腹、两侧留空；桥面与桥下净空来自同一轮廓 | 同名 `.prompt.txt` 和 `.source.json` |

使用内置 imagegen 生成透明位图，参考项目自有概念图。工具没有返回可确认的模型版本，因此不把来源标为特定模型，也不称作人工手绘。完整提示词、参考图和生成源文件路径均在上述记录中。

可站立实体沿原图中粗根和断面手动追踪；叶冠、细梢与纸墨晕染不作为厚实体。不能以矩形包围框填住空腔，不能增设原图没有的隐形踏面。细小非实体部分仍随所属物件换层，而不是另做不可搬的同类布景。

两张母图支持轮廓派生，但本轮先验证完整母素材的空间作用。原图中的破口、曲背和根腹需要同时影响外观、点选与实体；衍生素材须保存各自的裁区、轮廓与使用位置，不能只换颜色重复摆放。

角色分件母图与拼装参数在 `Art/Player/V6/`；它保留 C 款长发、修长叠页衣、植物纹样和红围巾，使用连续分件动画。原始透明图、提示词与来源见该目录的 `Generated/`。
