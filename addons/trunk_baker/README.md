# Trunk Baker

独立的 Godot 编辑器插件：从矩形 Ground 生成浅棕底色、棕色波点、三段明暗与手绘描边，并保存完整的 `LayerObject` 场景。游戏直接读取保存的 PNG，不运行材质生成程序。插件不依赖 Soil Baker 或 Leaf Baker。

## 使用

1. 选择挂载 `Layer_Object.gd` 的 `StaticBody2D` Ground。它需要 `CollisionBox : CollisionPolygon2D` 和 `VisualRoot : Node2D`，碰撞多边形必须为按边界顺序排列的四顶点矩形。
2. 在右侧 **Trunk Baker** 面板调整颜色、描边、波点、阴影和输出参数，点击 **预览**。
3. **换一组变化** 更换描边变化与波点相位。输入相同 Seed 可以重复得到相同结果，**加载参数** 可以读取已保存的 `TrunkBakeProfile .tres`。
4. 点击 **生成并保存树干**。输出到 `res://Generated/Trunk/Leaf_001/` 等自动编号目录。
5. 将生成的 `.tscn` 拖到目标 `DepthLayer` 下，按原 Ground 的位置放置。工具保留源 Ground。

输出按需求保留 `Leaf_编号` 前缀，使用独立的 `Generated/Trunk/` 目录，与树叶素材分开。插件可以在 **项目设置 → 插件** 中独立启用或关闭。

## 材质

- **矩形**：没有圆角。实体碰撞与选取区域均保持四顶点直角矩形。
- **颜色**：默认浅棕底色、棕色圆点、近黑色描边，均可调整。
- **描边**：默认宽 2px，抖动 0.6px，波长 18px，以最终 PNG 像素为单位。使用平滑噪声，靠近拐角渐弱，四个拐角固定，连接采用直角。
- **波点**：默认间距 4 个本地单位、行距约 3.464，半径为间距的 0.32；相邻行水平错开半个间距。横向间距、行距比例和半径均可调整。
- **阴影**：按矩形本地宽度三等分，从左到右为 30%、15%、0% 黑色遮罩。分界固定在 `W/3` 和 `2W/3`，是贯穿高度的直线，不随长宽比改变方向。深、浅阴影强度可以调整。
- **叠加顺序**：底色 → 波点 → 阴影 → 外描边。阴影同时压暗底色与波点，两个遮罩区域不重叠。

输入的顶点起点与顺逆时针顺序不影响结果。矩形可以在碰撞节点中平移、缩放或旋转；其变换会烘焙到输出的矩形与纹理坐标架中。源 Ground 的根变换由放置场景实例时设置，生成场景的根节点、`CollisionBox`、`VisualRoot` 变换归零，避免重复应用碰撞变换。

## 输出与内存

每个素材目录包含 `.tscn`、PNG、参数 `.tres` 和生成记录 `.recipe.json`。根节点为 `StaticBody2D`，使用原有的 `Layer_Object.gd`，保留源 Ground 的导出参数、碰撞层、遮罩和物理材质。`VisualRoot/Area2D` 对应现有点击系统；没有源选取区时，按源节点的 `can_transfer` 决定是否可点击。

默认每块有效尺寸不超过 1024px，PNG 每侧含 4px 采样边距；超采样缩小后会裁掉额外工作边距，以保持分块滤波一致。窄长树干按实际宽度生成，不补成方形纹理。生成时逐块写入，像素密度决定总纹理面积，分块尺寸影响单张大小和生成峰值内存，超采样只影响生成质量和峰值内存。

面板提供完整分辨率的 RGBA8 内存估算。取消或失败时，已写入的文件保留在面板提示的目录中，后续生成使用新编号。
