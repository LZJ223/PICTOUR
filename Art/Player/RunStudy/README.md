F6打开 `Run_Study_Lab.tscn`：左侧是现有V6，右侧是新的独立候选。两者真实速度均320px/s、同尺寸、同纸色背景。Space暂停／继续，1–4冻结双方位移并即时查看候选关键姿态，0恢复跑动。下方四个完整皮肤姿态始终可对照。

候选完整左右周期0.64秒，单脚支撑占20%，即0.128秒、40.96px地面行程。它不是把V6慢放：收膝、承重、蹬离、伸腿有自己的关键姿态和不等相段。前裙弧形体积、折膝遮挡、后片内侧、胸腰柔弧及头发延迟一起参与动作。近远腿在这项绘本造型实验中使用作者化侧投影姿态与曲线笔触，不声称是固定骨长人体模拟。

皮肤沿用AI生成的 `Art/Player/V6/Generated/Traveler_C_Rig.png`，只在Godot内进行UV与网格派生；未修改原像素。V6来源记录仍在该图同目录。此目录新增代码未改动V6、F5、Story、Vertical或共享控制器。

视频为 `Exports/Run_Study.mp4`，4秒、60fps、240帧；截图在 `Exports/Run_Study/`。这些导出产物不入Git。`Tests/Run_Study_Check.tscn`验证循环接缝、姿态速度连续与支撑脚世界位置；`Tests/Run_Study_UI_Check.tscn`实际触发四个姿态键、冻结和恢复。功能底线通过不能证明动画优雅。

本候选只验证平地奔跑的制作方向。它没有待机、跳跃、转向、坡面或正式状态机，不可直接替换游戏角色。与GRIS的完成度仍有距离，是否改善到值得继续制作，交由用户观看真实视频判断。方法复盘见 `ProjectLogs/GRIS跑动对照_2026-10-09.md`。
