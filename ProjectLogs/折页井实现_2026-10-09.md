# 折页井：三主体纵向空间实现

独立入口 `Vertical_Garden_Game.tscn`，打开后 F6。它是两个景别、三件主实体的短空间研究，不替代完整序章或第一章地图。F5、既有叙事庭园、旧存档均由主 agent 单独管理；本研究场不创建 `BookmarkManager`，不读写磁盘存档。

## 实际实现

空间横向约2240px，玩家从脚位1100上行到180，总爬升920px。固定地平线采用圆钝的折岸与厚薄变化，井底留下凹地、上方留出折页间的空白；其实体轮廓与墨面来自同一组坐标。背景世界底面也注册真实碰撞，因此背景有可用容积，不再是能够任意叠放实体的仓库。

独立可选物件只有三件。树叶、种穗和干木纹路是这些物件的附属外观，不另铺一排装饰件；没有不可搬的完整树或建筑。世界纸面、色洗、折岸与终点墨晕固定。

| 主体 | 实际形态和作用 |
|---|---|
| A 卷根门 | 新生成父图等比缩放0.25；树根斜坡与四个断肩分别提供约1005、962、912、882px的踏面。保留在中景时可登高，但阻挡地面直接穿行；送入背景后打开井底。拱腔真实为空，右侧悬根也有碰撞。 |
| B 垂腹枝 | 新父图在背景按0.375等比显示，搬入中景后约0.30；实际木体宽约409px。顶面沿图自然下凹，端部与窄垂腹均参与实体。高位形成跨接，腹尖挡住井底；稍向左的位置给腹尖下方留下完整人物净空。 |
| C 余根 | 复用古木父图裁片 `low_root`，背景尺寸225×119.4px，中景约180×95.5px。两路共用同一末段登高件，真实断面到平台约91px；没有配发第二套完整楼梯。 |

新A/B PNG未做程序改图、拉伸或重绘；实体沿原图木缘手追，空白与薄叶不充当隐藏踏面。来源和生成提示词由主 agent 记录在 `Art/VerticalGarden/README.md`。C来源见 `Art/SceneryFamilies/Crops/README.md`。

## 可实际行走的两条路线

高路：保留卷根门，沿斜根和断肩爬到根冠；约x840时选中背景垂腹枝，W搬近。在枝面上向右跑跳到上岸，走到右端约x1860把余根搬近，借其断面上到更高的折岸，抵达余墨。返程沿相同物件逐段落回根门与前庭，全程不需要Z或R。

低路：在前庭约x480先把垂腹枝搬近，腾出背景空腔；退到约x290再把卷根门送远。沿井底穿过枝腹下方，走到右侧回折坡尽头，向左跳上中间页岸，再使用同一余根登高。返程从右侧落回缓坡，穿过仍然敞开的井底回到前庭，也不需要撤回。

以上坐标是可复现的测试站位，不是要求玩家精确踩中的触发点。所有成败由实体轮廓和视差位置决定，未写“这件物件只能放在这个槽”的特殊分支。主要必须上跳的高度约88–91px，保留约17–20px的满跳余量；四个根肩中后几级更低，玩家有跳过个别断肩的可能。

高路枝桥的位置与低路位置相差约73px，源于两次不同站位的投影。回归还会实际送远根门，确认高路枝桥的腹尖能阻挡井底通行；低路则真实走过这段净空。背景折壁限制存放空间，但没有新增不可读的空气墙。

尚未穷举其他解法。例如从根门爬高后直接下落到井底，可能产生第三条混合路径；本轮保留这种开放性，不声称只有两种解法。两条记录路线的往返已验证，也不等于任意摆放都不需要撤回。

## 投影、撤回与角色

系统来自 `System/Study/Study_System_Controller.gd`，由系统子 agent 维护。物件的视觉、目标预检和真实搬运统一用 `(player.x,720)` 作投影锚点。镜头上下观察有65px死区，并限制观察范围；跳跃和上行不会改动背景相对于玩家层的纵向解谜坐标。

普通W/S始终检查目标层的物件、地貌和玩家，两个景别都不豁免实体遮叠。选中时显示目标轮廓与实际碰撞接触点。Z退回上一次成功换景前的**整套摆位和玩家状态**；R回到本研究初始摆位、清空临时操作历史。失败动作不进入撤回历史。余墨到达标记在本次运行内保留，重开场景清除，不写旧关卡进度。

本场已接 `Component/Player/V6/Traveler_V6.tscn`。实体仍30×86，速度180/320/560px/s，满跳约108.6px；美术和连续分件动作的说明由角色 agent 维护。原V5仅用于最初搭建时的物理校准。

初屏与上缘的场景丰富度仍未达到定调图，当前曲岸和三主体构图是可玩的机制研究候选，不是美术终稿。下一轮可围绕主体的生长、依托和坍塌关系添加少量派生细节，不宜复制完整树填空。

尚未完成玩家主观美术验收、完整序章流程、章内永久存档或Windows导出包。这个研究的用途是判断三件主体是否已经形成清楚的空间关系、双向道路和可恢复的试错，再决定是否扩展。
