# PICTOUR 开发日志｜2026-10-11

## 今日概览

今天完成了基于 2.5D 图层的整体后处理系统。每个 `DepthLayer` 现在会先通过 `CanvasGroup` 合成为一个完整画面，再统一应用前景模糊与压暗、后景线性雾以及整层外描边。滤镜只关心图层当前所在的槽位，不需要让着色器识别单个物体的图层信息。

同时整理了图层与物体的 Z 轴职责：普通物体不再单独设置显示深度，图层间排序统一交给 `CanvasGroup` 根节点；跨层影子由于仍挂在投影物体下，暂时保留独立深度。

> 今日尚未产生新的 Git commit。本日志以当前工作区中的实际代码和场景差异为准。

## 一、整层 CanvasGroup 合成

### 1. 图层根节点改造

`DepthLayer` 从普通 `Node2D` 改为 `CanvasGroup`。地面、物体及其视觉子节点会先进入图层自己的后备缓冲，再由挂载在图层根节点上的材质进行一次统一绘制。

这使模糊、雾效和描边的处理对象从“某个物体”变为“整个图层的最终画面”，物体本身不需要单独挂载景深材质。

每个图层使用独立的 `ShaderMaterial` 实例，避免一个图层修改参数时同步影响其他图层。当前后备缓冲设置为：

```text
fit_margin   = 32 px
clear_margin = 32 px
```

该空间用于容纳模糊和外描边超出原始图层边界的像素。

### 2. 图层排序职责统一

图层根节点根据当前槽位统一设置 Z 轴：

```text
z_index = (layer_count - slot) × 100
```

`LayerObject` 不再修改自身或 `VisualRoot` 的 `z_index`，所有普通物体直接继承所属 `CanvasGroup` 的深度。这样既减少了重复状态，也保证参与整层滤镜的内容处于同一个合成层级。

玩家仍位于图层系统之外，因此继续使用独立 Z 值显示在关卡层上方。

## 二、前后景滤镜

系统根据图层槽位与关卡层的相对距离计算滤镜：

```text
relative_depth = slot - current_layer_index
```

- `relative_depth < 0`：图层位于关卡层前方；
- `relative_depth = 0`：当前关卡层；
- `relative_depth > 0`：图层位于关卡层后方。

### 1. 前景效果

前景层使用 mipmap LOD 实现低成本模糊，并附带少量压暗。距离关卡层越远，效果越强：

```text
blur = min(front_distance × foreground_blur_step, maximum_blur_lod)
darkness = clamp(front_distance × foreground_dark_step, 0, 0.6)
```

只有前景图层会启用 `CanvasGroup.use_mipmaps`，关卡层和后景层不会承担无效的 mipmap 生成开销。

### 2. 后景效果

后景层以雾效为主。雾浓度随图层距离增加，并在单个图层内部按照屏幕纵坐标从上到下线性增强：

```text
fog = clamp(back_distance × background_fog_step, 0, 1)
fog_gradient = screen_uv.y
```

当前雾效不依赖噪声贴图，颜色和透明度统一由 `background_fog_color` 控制，便于白模阶段快速调整整体空间层次。

### 3. 关卡可调参数

`Level` 新增“图层滤镜”参数组，当前包含：

| 参数 | 作用 |
|---|---|
| `foreground_blur_step` | 前景每层增加的模糊等级 |
| `foreground_dark_step` | 前景每层增加的压暗强度 |
| `background_fog_step` | 后景每层增加的雾浓度 |
| `background_fog_color` | 后景雾颜色和混合强度 |
| `maximum_blur_lod` | 最大模糊等级 |
| `layer_outline_color` | 整层描边颜色和透明度 |
| `layer_outline_width` | 关卡层描边的基准宽度 |

滤镜参数只在图层相对位置发生变化时写入材质，不需要每帧重复设置。

## 三、整层外描边

### 1. 基于最终轮廓生成

描边不是对每个物体分别处理，而是对 `CanvasGroup` 合成后的整层 Alpha 进行采样。着色器在当前像素周围进行 16 方向采样，并使用下面的差值生成外描边：

```text
outline_alpha = max(surrounding_alpha - center_alpha, 0)
```

因此，相互重叠的物体会先合并为一个整体轮廓，不会在重叠区域产生内部白线；互不相连的物体则分别显示外边缘。

### 2. 后处理顺序

当前处理顺序为：

```text
整层合成 → 模糊/压暗/雾效 → 根据处理后的 Alpha 生成描边 → 输出画面
```

描边采样使用与图层模糊相同的 LOD，因此前景层会先形成模糊后的轮廓，再在该轮廓外生成白边。雾效目前只改变颜色、不改变 Alpha，描边在雾效之后合成，不会被雾色覆盖。

### 3. 描边随图层缩放

`layer_outline_width` 表示关卡层的基准宽度，实际传入着色器的宽度为：

```text
actual_outline_width = layer_outline_width × layer_scales[slot]
```

因此，前方放大的图层具有更粗的画面描边，后方缩小的图层描边也会同步变细，保持描边与图层整体缩放的一致性。将基准宽度设置为 `0` 可以关闭描边。

## 四、影子与图层滤镜的当前关系

普通物体已经完全由所属 `CanvasGroup` 管理显示深度。跨层影子目前是一个例外：影子视觉节点仍挂在投影物体下，但需要显示在后方目标层，因此继续使用独立的绝对 Z 值。

这意味着当前版本中：

- 普通图层内容会参与对应图层的模糊、雾效和描边；
- 跨层影子仍按原有目标深度显示；
- 影子暂时不会成为目标层 `CanvasGroup` 合成轮廓的一部分。

如果后续需要让影子同时接受目标层滤镜和整体描边，应将影子视觉节点挂接到目标 `DepthLayer`，同时保留投影物体对影子几何和状态的引用。

## 五、着色器资源整理与兼容修正

图层滤镜和鹰眼灰度着色器统一整理到 `Shader` 文件夹中，`LayerObject` 的鹰眼预加载路径同步更新。

验证过程中处理了两项 Godot 4.7.2 着色器兼容问题：

1. `TAU` 已是着色器内置标识符，自定义常量改名为 `OUTLINE_TAU`；
2. 当前 CanvasGroup 着色器上下文无法使用 `SCREEN_PIXEL_SIZE`，改为通过 `textureSize(screen_texture, 0)` 计算单个屏幕像素对应的 UV 尺寸。

## 六、原型场景调整

`Prototype_Level` 中的四个图层分别保存独立的本地 ShaderMaterial，确保图层轮换时每层能够持有不同的实时参数。

当前主场景暂时改回加载 `Prototype_Level`，用于集中验证：

- 四个图层的整体滤镜；
- 图层轮换后的参数更新；
- 前后景视觉差异；
- 整层描边；
- 影子与 CanvasGroup 的排序关系。

原型关卡原先针对各层地面设置的独立颜色覆盖已移除，层级差异现在主要由统一滤镜表达。


无界面运行能够确认资源、脚本和着色器正确加载，但不能代替带画面的人工观察。仍需在编辑器中重点确认：

1. 前景模糊与后景雾效的默认强度是否合适；
2. 图层轮换后滤镜和描边是否立即跟随槽位变化；
3. 模糊后的描边是否存在过宽、过软或边界截断；
4. 多个物体距离较远时，CanvasGroup 后备缓冲范围对性能的影响；
5. 跨层影子未进入目标层滤镜时的视觉差异是否可以接受。

## 九、当前边界与后续工作

1. 描边每像素最多执行 16 次周边采样。若正式关卡出现明显性能压力，可以降低采样方向数量，或改为低分辨率遮罩与两阶段膨胀。
2. `CanvasGroup` 的处理范围由全部子物体的包围矩形决定。物体分布很远时，中间透明区域也会进入后备缓冲，应在正式关卡中使用性能分析器验证。
3. 当前 `32 px` 边距足以容纳白模阶段的模糊和描边；若后续提高最大描边宽度，需要同步增加 `fit_margin` 和 `clear_margin`。
4. 影子若要完整参与目标层的滤镜和描边，需要进一步调整视觉节点归属，而不能继续只依赖跨层 Z 排序。
5. 目前滤镜参数按相对层级离散变化。后续如果加入连续景深动画，可以在图层轮换期间对参数进行插值。

今天的更新建立了统一的图层视觉管线，使图层远近关系不再只依赖缩放和移动速度，也能够通过模糊、雾效和轮廓共同传达空间层次。
