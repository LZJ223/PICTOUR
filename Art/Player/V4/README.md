# C 方案：长发叠页旅人

用户于 2026-10-09 选择 `Female_Traveler_Choices.png` 的 C 方案。当前是 **AI 生成手绘风位图**接入样板，保留修长的非对称叠页衣、长发、植物印纹、朱砂围脖和独立红围巾。设计图与动作母图由内置 imagegen 生成，并非人工逐帧手绘；没有把设计图重新描成程序几何人物。

## 入口与实际参数

- 角色：`res://Component/Player/V4/Traveler_V4.tscn`。
- 动作观察场：`res://Art/Player/V4/Traveler_V4_Lab.tscn`，F6；Space 暂停，R 重播，1 原尺寸，2 放大。
- 行为检查：`res://Art/Player/V4/Traveler_V4_Check.tscn`。
- 位移速度为步行 180、奔跑 320、短冲 560px/s。V4 场景独立覆盖速度，没有更改共享控制器默认值；V3 保留 250/400。
- 碰撞 30×86，跳跃 610、重力 1800，实测满跳约 108.6px。角色站立画面约 95px 高，不按角色图片改变碰撞和地面位置。

## 母图、帧与锚点

`Generated/` 保留三张 AI 生成的透明 RGBA 母图、完整提示词和来源说明。每张 1536×1024，名义格网 4×2，包含 walk 8 帧、run 8 帧及待机/跳跃/落地/停步 8 帧。它们是候选关键姿态，不因生成了相同人物就视为已通过动画验收。

`Traveler_V4_Layout.json` 记录各帧在母图中的真实区域、物理足根与后领结锚点。生成图少数脚尖越过名义格线，因此区域按真实主体扩大，不沿 384/512 的分格线切断脚趾。区域可跨格，但不能带入邻格人物碎片。原 PNG 像素完全保留；`AtlasTexture.region` 裁取主体，`margin` 放入共同的 640×640 透明虚拟画布。所有帧使用同一 0.2 倍缩放，不逐帧缩放人物。

步行各帧足点保持地面基准；奔跑的第 3/7 帧保留真实离地高度，不把其最低像素强行拉到地面。上升、顶点与下落亦保留对应的蜷腿姿势。每帧后领结坐标供连续布条使用，围巾不会固定粘在与人物动作无关的世界点上。

资源生成命令（先让 Godot 完成母图导入）：

```powershell
& $godotExe --headless --path . --script res://Art/Player/V4/Build_Traveler_V4.gd
```

`Build_Traveler_V4.gd` 只读母图并输出 `Traveler_V4_Frames.tres` 与 `Traveler_V4_Metadata.json`。它不是运行时图像处理，也不参与导出后的游戏。

## 播放与布料

播放器消费碰撞完成后的实际水平位移；顶墙时不继续播放走路。反向输入须待速度过零再镜像。步行周期位移 108px，奔跑 152px，对应满速约 3.33/4.21 步每秒，避免上一版走路反而比跑步更密。没有重新引入站立与步行两套不同髋高的程序骨架。

围巾由 V3 长度/弯曲约束的独立副本发展，当前长 74px、宽 7px；布条带固定在材质上的纸墨纹理，恒速收敛，启停与转向产生余摆。人物的身体、头发、衣摆来自原图关键姿态；围巾为独立程序布条。物理帧更新质点，显示帧只请求插值重绘，不向角色或相机写入物理变换。

## 验证与限制

2026-10-09：检查场景 72 项通过，覆盖原始位图引用、统一画布、足点、起步高度连续性、奔跑离地、真实走跑/转向/跳跃/顶墙及围巾长度。D3D12 Mobile 实际 GPU 观察场运行 480 个物理帧，无脚本或渲染错误；确认透明母图没有带出预览中出现的褐色矩形，截图在 `Exports/Traveler_V4_Lab/`。

本轮未把 8 帧图集称为最终动画：绘制姿态的身体一致性、手臂配合、帧间节奏与游戏中喜爱度仍需要用户审阅。当前脚步是离散位图，足根对齐并不等于每一物理帧的支撑脚都连续锁定。后续若要更细腻，应围绕选定侧姿补绘和调整时序，而非仅增加重复帧或回到几何火柴人。
