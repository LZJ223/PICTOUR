# 叙事庭园固定地貌

`Story_Bank.gd` 为可碰撞的玩家层世界底面，继承 `PaperIsland`。`edge` 按左到右描摹上沿，`underside` 按右到左独立描摹下沿；两者围成一个不自交轮廓。下沿加入静态细小侵蚀，绘图与实体使用同一轮廓，上沿保持设计位置。碰撞多边形直属物理物体，图像表面引用已有AI干墨纹理。`show_strata` 默认关闭，避免长平行线破坏纸墨风。

`Background_Landform.gd` 为固定背景地平线，继承 `LayerDecoration`，直接放在对应 `DepthLayer` 下。使用相同上下轮廓约定。其视觉根随本层倍率和物理帧投影，因而景物的根与地势保持依托；下沿可用 `bottom_fade` 淡入纸面。这一类不包含完整树、石或拱门，也不生成不可选择的同类副本。

背景地平线当前没有角色碰撞：序章不允许玩家换入背景。后续开放移动自己时必须补真实地面和进入安全性检查，不能将现有外观支持理解为四层地形已完成。

关卡布局由 `Level/Story_Garden_Level.tscn` 保存。几何自交会明确报错，不自动改轮廓；主路径与两条组合路线通过 `Tests/Story_Garden_Regression.tscn` 真实运行检查。两层投影与材质的实际图像需在GPU中复核，自动测试不代替构图判断。
