本轮从现有纵向折页井继续建立可试玩的大地图，使用 C 款长发叠页衣的 V7 角色。入口为 `Illustrated_Garden_Game.tscn`，布局保存在 `Level/Illustrated_Garden_Level.tscn`；旧 Story / Vertical / Prototype 场景与共享 System 保留。当前是 `dev` 上未提交的实验成果，没有暂存、提交、推送或打包。

## 从参考图落实的设计规则

用户三张 GRIS 截图用于理解构图与路径，不直接复制截图或抽取游戏资产。本轮提取连续的大形、空腔与断口的因果关系、同一断体的子片、大小尺度对比、疏密与留白。通路由根门的断肩、页塔的阶状残边和横根的真实上沿产生；不存在另铺一套隐形楼梯来补图。背景浅鼠尾草色，中景用较深的紫褐页石；围巾继续承担角色的红色视觉锚点。

固定世界地貌只有连续岸体及抽象纸面色洗。独立树、根、拱门、石片、花草都属于可换层的景物，不额外放一套看起来相同但不能搬的背景树。地貌内部的曲页纹、化石印迹属于表面绘画，不单独作为机制体。

本轮新增两个透明父素材：`Art/IllustratedGarden/Generated/Page_Spine_Tower.png` 与 `Fallen_Page_Bridge.png`；新增地貌内部材质 `Page_Strata_Surface.png`。原 PNG 保留，生成提示词与来源记录由主 agent 保存。用资源中的原图区域和多边形掩片派生断肩、桥端及页石碎片，原图没有被覆盖或重绘；这些仍是 AI 辅助素材，不称为人工手绘。

## 可玩结构

地图有效横向通路约 4600px，从初始脚点 Y1300 到东天际脚点约 Y80，纵差约 1220px。它是上下通路和回环的机制实验，不是完整第一章或完整序章。

| 区域 | 同一景物的作用 | 已验证的通行方式 |
|---|---|---|
| 根井 | 根门既可攀登也可搬走；枝桥既能接高路，也会以垂腹占用井底 | 保留根门登高、在根冠处搬入枝桥走高路；或先在低位搬入枝桥，再把根门送远走井底。两条路线均能走到西上缘并自然返回 |
| 页脊断肩 | 页塔有空拱洞、窄门槛和真实阶状肩；背景横根在正确视差位置才能接断口 | 沿页塔肩部攀登，早换层会真实撞岸而拒绝；走到断肩边再把横根搬入，接向东岸 |
| 天际回廊 | 上岸和下岸成对断裂，外沿留下完整身体的绕行净空 | 沿东下岸走到上岸尖端外侧，反向跃回上岸；之后经外缘下降至低谷 |
| 低谷回环 | 页塔可退入其背景拱腔，低谷不再被塔根占住 | 从右侧把塔送到背景后，通过低谷和根井自然回到出生处，最后这一整条回环不用 Z/R 代替归路 |

场景中 20 个独立景物都可换层，其中 5 件承担主要机制，其他为同族断片与非实体植物。数量用于解释布局规模，不代表谜题丰富度或美术已通过验收。四滴记忆只保存在本次运行内；尚未接入永久收集、房间画卷、正式书签或剧情。

操作沿用 A/D、短按 Shift 冲刺 / 长按奔跑、Space 跳跃、左键选景、W/S 换层。此实验两层均执行严格实体占用，并保留成功操作前的整场景内存历史：Z 原子撤回，R 恢复初始布局并清空历史。R 当前是研究场重置，不是用户最终设想的最近保存点。F8 可隐藏研究说明。背景植物允许视觉遮叠但没有阻挡实体，实体景物不以忽略背景碰撞规避摆放问题。

## 与 Godot 布景面板共用的契约

地图完全由静态 `.tscn` 节点组成。可搬景物直接挂在 `Mid` 或 `Back` 的 `DepthLayer` 下，固定 `layer_id=0/1` 与 `slot=0/1`。实例根节点保存摆位，图像和碰撞由素材资源统一生成；不要只翻 Sprite，也不要移动 VisualRoot 或 CollisionBox 伪造摆位。

`Component/IllustratedGarden/Illustrated_Piece.gd` 是 `@tool` Resource，记录原 PNG、可选裁框、像素根点、单位缩放、真实实体轮廓、点选轮廓、可踏边与局部掩片。`Illustrated_Object.gd/.tscn` 为可摆放的 `@tool` 景物；导出 `piece`、`mirror_x`、`size_multiplier`、`variant_tint`，并提供 `get_editor_geometry()` 返回局部 `solids` 与 `walkable`。镜像同时影响外观、实体和点选，花草只有点选不生成挡路实体。根门四段可踏边按真实断肩分开标注，预览不会跨空气画出一条虚假踏面。

`Illustrated_Terrain.gd` 用左到右的 `upper` 和右到左的 `lower` 定义完整岸体。实体、可视填充和面板占用预览使用同一轮廓，背景世界地貌也有其层的实际物理占用。编辑器生成节点不写入场景 owner，只保存作者设置的导出参数。

`Level.spawn` 与 `Level.editor_projection_anchor_y` 是出生点和投影 Y 的单一来源；总装脚本在子节点入树前应用它们，System 在建立初始历史前读取同一个投影参数。默认 Y920；与面板没有另一个独立的 Y720。已检查变参出生点 `(410,1300)`、投影 Y880 以及 R 初始历史中的 Y880。

Godot 布景面板由另一个 agent 实现于 `addons/pictour_garden_editor/`。它读取同一静态景物和素材目录，采用原生撤回 / 重做与场景保存；本地图没有另建运行时地图编辑器或第二套布局文件。

## 实际发现与修复

1. `RootShelf` 的 `edge_rounding=0` 原先仍为每个点生成七个重合顶点。三角化成功并不代表物理凸分解成功，真实启动报 `Convex decomposing failed!`。现在零半径直接返回原轮廓，专项检查物理凸分解，不凭退出码忽略错误。
2. 固体子片按根点贴坡，仍可能让左右轮廓嵌入固定岸体，导致初始状态无法原子恢复。现在依完整实体边界与本层岸上沿计算落点，再检查实际占用。四个固体子片初始状态合法，Z/R 恢复验证通过；不是删除恢复校验绕过。
3. 天际上岸下脊与下岸上坡形成头顶夹缝，路线曾实际停在 X4251、X4338 和 X4364。按 86×30 全身及坡面足宽净空调整成对断口与外缘绕行，玩家真正走到上岸尖端外侧再反跳；没有只改测试目标或增大跨步阈值。
4. 天际的小石片曾阻挡斜坡步行，已缩为可真实跨过的小残片，并把下岸回程拱腹抬到有完整身体净空的位置。
5. 初始背景两株植物以名义根点摆放仍显悬空，最终按可见根端向下嵌入本层岸面。没有把包围框底误当根端。

第二轮大形审图后扩展根井下缘的根脚和空腔，厚度有轻重变化；页肩收向塔肩的断口，背景后岸贯穿东侧竖向空间。第三轮删掉临时扇形印章装饰，改用局部页石内纹 shader，避免靠散件填空。最终地貌混合比例为 0.54；背景更浅且对比更低。仍有些大岸体的轮廓偏几何切片，画面惊艳程度、自然融合与大地图节奏需要用户实际审阅，不以自动测试宣布美术定稿。
