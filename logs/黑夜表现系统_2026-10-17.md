# 黑夜表现系统

`Level_09`～`Level_12` 的 `is_night` 已开启。黑色背景图仍待美术补充；目前保留项目原有背景色。

## 运行结构

`Game/NightRenderSystem` 管理本关的 GPU 遮罩图集、轮廓遮光体和空气光束。它在 Game 初始化完成后启用，随 Game 一起释放。白天关卡不分配离屏视口。

- `Player/LightOrigin` 是固定在头部基准位置的 Marker2D，自动继承角色缩放与无人机回收变换，不跟随待机晃动。光源位置与相机景深锚点分开计算。
- `ShadowedGeometry.get_projection_transform()` 返回真实投影的仿射矩阵，GPU 绘制与实体切割使用同一公式。
- `ShadowMaskAtlas` 是独立 World2D 的 SubViewport。四格分别绑定物理 `layer_id` 0～3，不能用会循环变化的 `slot` 作为身份。图集只绘制投影轮廓，不重复渲染场景物体。
- 每帧同步变换；只有物体生成、轮廓变化或销毁时，才创建、更新或释放绘制节点。没有每帧多边形布尔运算、CPU 图片上传或纹理回读。
- `render_shadow_mask` 是全局 sampler2D，供图层 Shader 在全部调色和受光之后读取。覆盖内部的 RGB 置零，Alpha 保持目标图层本身的值，因此所有目标物体都接影，透明镂空与物体间隙不会被填黑。
- 夜间环境亮度、表面提亮仅作用于当前关卡平面。其他层保留项目原有景深滤镜的结果，只有实际被投影覆盖的部分置黑。整层轮换时按连续景深淡出、淡入受光效果，不绑定物理层编号。
- `LightOccluder2D` 复用物体碰撞轮廓并跟随 VisualRoot，只让接近当前关卡平面的遮光体进入 SDF。关卡层像素沿入射方向寻找表面，根据距表面的距离、表面朝向和光源距离计算提亮；背光或被其他物体遮住的区域只保留环境亮度。采用入射方向寻找表面，避免最近边法线在矩形中轴线形成突变的三角亮斑。
- 表面和空气通过 `Night_Light_Common.gdshaderinc` 共用遮挡查询，步数不足视为不通光。深处与光照范围外的实体像素跳过射线步进。没有逐帧 CPU 射线检测。
- 空气光束包含暖色通光区和明显的遮光暗区，边界由实际关卡层轮廓形成。空气在所有实体后方绘制，避免改变其他层的正常亮度，也不会再次照亮纯黑影子。这里使用 Light2D 系统的遮光体及 SDF，不额外叠加 PointLight2D，避免对 CanvasGroup 和其子物体重复照明。
- 黑夜雾保持原纹理的 Alpha、流动、视差和景深模糊，RGB 改为黑色。

原有静止两秒后的 `SignalSystem.shadow_boolean` 保留。此时才调用 `Geometry2D.clip_polygons()` 更新 `can_be_shadowed` 物体的实体和碰撞轮廓。能否被切割与能否接影是两个独立规则。新碎片会自动进入下一帧的遮罩和遮光体同步。

## 参数

在每关 Level 根节点的“黑夜表现”分组调整参数：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `night_ambient` | 0.38 | 仅关卡层的无直射光亮度 |
| `night_light_color` | 暖白色 | 表面与空气共同的光色 |
| `night_light_radius` | 750 | 世界坐标中的照明半径 |
| `night_surface_width` | 24 | 表面亮度向实体内部衰减的距离 |
| `night_surface_energy` | 2.6 | 迎光表面提亮强度 |
| `night_ray_energy` | 0.65 | 空气通光区、遮光区的对比强度 |

`NightRenderSystem.mask_resolution_scale` 默认 1.0，四格图集各自与逻辑视口等分辨率；性能受限时可改为 0.5。数据图集不使用 mipmap，也不进行 sRGB 颜色转换。

## Level09 的观察条件

原场景箱子均贴在同一高度的地面上。光源改为头部后，跨层投影大多落到更后方的地面上，并被前面的地面挡住。因此初始站位看不见明显跨层黑影，并不能单独判定图集未渲染。此前所有层又被夜间环境色统一压暗，进一步掩盖了这一现象；本次已撤掉非关卡层的额外压暗。

回归测试用真实 Level09 的箱子，在内存中暂时抬高一个投影物体 40 单位，验证后方箱子的可见像素为纯黑；关闭图集后，同一像素恢复原色。随后暂时隐藏前方地面，验证普通 Soil 也接影。测试会恢复这些状态，不修改保存的关卡布局。若需要初始站位就明显展示跨层投影，可在关卡设计中安排投影物体与接影面的高度差。

## 验证

在项目目录运行真实渲染测试，测试会打开游戏窗口并自动退出：

```powershell
& "C:\Program Files\Godot\Godot_v4.7.2-stable_win64_console.exe" --path . res://tests/night_render_test.tscn --max-fps 60
```

不能加 `--headless`，因为需要读取实际渲染结果。测试阶段的截图回读仅存在于测试脚本，不在游戏每帧路径中。

检查包括真实箱子和普通地面的纯黑投影、遮罩开关对照、非关卡层的原亮度对照、透明空气亮暗差异、表面遮挡、接影之外的空白、贴图透明洞、迎光/背光差异、每帧移动无拖影、头部光源、镜头变化、双向整层轮换、单物体换层、碎片生命周期、实际两秒计时切割、四个黑夜关卡、无人机、窗口变化，以及返回白天和菜单后的全局资源清理。

截图与 JSON 报告保存在忽略的 `.godot/night_qa/`。`01_level09.png` 为原始布置；`01b`、`01c` 为上面说明的真实物体接影诊断；`02`、`02b` 为隔离后的受光和遮挡探针。

报告的 `night_sync_cpu_p95_ms` 只测量夜景同步代码；`level09_measured_fps` 受到帧率上限、垂直同步和系统计时精度影响，不代表其他设备的性能保证。需要比较渲染开销时可用 `--max-fps 0 --disable-vsync`，报告同时记录仅表面、仅空气和关闭照明时的帧率。

实现依据：[Godot CanvasItem SDF 函数](https://docs.godotengine.org/en/stable/tutorials/shaders/shader_reference/canvas_item_shader.html#sdf-functions)。
