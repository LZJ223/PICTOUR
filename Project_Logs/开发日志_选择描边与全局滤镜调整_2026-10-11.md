# PICTOUR 开发日志｜2026-10-11｜选择描边与全局滤镜调整

## 今日概览

今天在现有整层 `CanvasGroup` 后处理的基础上，完成了物体选择描边系统，并重新整理了全局滤镜的效果与参数职责。

选择提示不再依赖各物体场景中的 `Line2D`，而是统一由 `LayerObject` 创建独立的着色器描边。新的描边能够适配 `Polygon2D` 和 `Sprite2D`，宽度以屏幕像素为准，不会随着物体或图层缩放而变化，同时不会被图层的模糊、压暗和偏色效果处理。

全局图层滤镜移除了整层白边和暂时不再使用的线性雾效，新增了对比度衰减、前景剪影化压暗，以及前后景相互独立的颜色偏移。所有公共渲染参数现由自动挂载的 `Renderer.gd` 统一维护。

> 本日志依据当前工作区中的实际代码与场景差异编写，相关修改目前尚未形成新的 Git commit。

## 一、选择描边系统

### 1. 统一选择接口

原有方案要求每个 `LayerObject` 子类分别查找并控制一个 `Line2D`：

```text
LayerObject 子类 → 获取 Line2D → 修改 visible
```

这种方式只适合人工维护的简单多边形，无法自然匹配精灵透明区域，也导致相同逻辑分散在 `Box`、`Platform`、`PlayerObject` 和 `ShadowedGeometry` 等脚本中。

现在 `set_pick_condition()` 已直接在 `LayerObject` 中实现，不再是抽象接口。子类只需要继承基础行为，无需单独维护选择节点或重写选中逻辑。

### 2. 独立描边视觉副本

`LayerObject` 初始化时会递归收集 `VisualRoot` 下的 `Polygon2D` 与 `Sprite2D`，为每个可绘制节点建立一个专用描边副本，并挂载独立的 `Selection_Outline.gdshader`。

描边没有直接替换原物体的材质，因此：

- 原物体仍可正常接受鹰眼材质与其他物体级视觉效果；
- 所属 `DepthLayer` 仍可对原物体进行整层滤镜处理；
- 选择描边使用自己的材质和显示顺序，不会与 `CanvasGroup` 材质冲突。

描边副本采用绝对 Z 值，绘制在所属图层合成结果的后一层：

```text
selection_z = layer_z - 1
```

着色器先扩张描边副本，随后原图层合成画面覆盖副本内部，只留下物体边缘外侧的白色部分。这样描边位于图层滤镜之后，不会被模糊、压暗或染色。

### 3. Polygon2D 与 Sprite2D 处理

两类视觉节点使用不同的轮廓来源：

- `Polygon2D`：复制原多边形几何，在顶点阶段沿轮廓外侧扩张；
- `Sprite2D`：扩张精灵绘制范围，再对原纹理 Alpha 进行 16 方向采样，只保留透明区域外侧的轮廓。

精灵描边会同步纹理、帧编号、区域矩形和 UV 范围，因此可以兼容基础帧动画与区域精灵。描边副本只在物体被选中时可见；未选中物体不会执行轮廓像素采样。

### 4. 固定屏幕宽度

描边宽度由全局参数 `render_selection_outline_width` 定义，单位接近屏幕像素。`LayerObject` 根据视觉节点的全局缩放和相机缩放计算补偿：

```text
local_outline_width
= screen_outline_width / (global_scale × camera_zoom)
```

因此，无论物体位于哪个图层、实际大小如何变化，最终画面中的选择白边都会保持近似一致的宽度。

## 二、全局图层滤镜调整

### 1. 移除整层描边与旧雾效

原有 `Layer_Depth_Filter.gdshader` 会为每个图层的最终合成轮廓增加白边。该效果容易与选择描边混淆，也会使画面边缘信息过多，因此已经删除。

旧的从上到下线性雾效也暂时移除。后景当前只负责对比度与颜色层次，体积雾将在后续形成更明确的视觉方案后单独实现。

### 2. 距离对比度衰减

滤镜继续使用图层相对关卡层的位置作为唯一局部状态：

```text
relative_depth = slot - current_layer_index
layer_distance = abs(relative_depth)
```

图层离关卡层越远，对比度越低：

```text
contrast = clamp(1 - layer_distance × contrast_falloff, 0, 1)
```

这一处理会逐渐压缩远处图层的明暗差异，降低视觉细节，使当前关卡层更容易被识别。

### 3. 前景剪影化

前景仍以 mipmap LOD 模糊为主，但压暗强度明显提高，并随前景距离累积：

```text
blur = min(front_distance × blur_step, maximum_blur_lod)
darkness = clamp(front_distance × darkness_step, 0, 1)
```

前景图层越靠近画面观察方向，越接近模糊的暗色剪影。后景不再进行自动提亮，避免与未来雾效的职责重叠。

### 4. 前后景独立偏色

前景与后景分别拥有自己的基准色和每层偏移强度：

| 参数 | 作用 |
|---|---|
| `foreground_tint_color` | 前景趋近的颜色 |
| `foreground_tint_step` | 前景每层增加的偏色强度 |
| `background_tint_color` | 后景趋近的颜色 |
| `background_tint_step` | 后景每层增加的偏色强度 |

两组颜色互不依赖，可以分别调整前景剪影和后景空间层次。任意强度参数设为 `0` 时，对应效果会直接关闭。

## 三、Renderer 全局参数系统

新增的 `Renderer.gd` 作为自动挂载脚本，集中保存以下参数：

- 前景模糊强度和最大 LOD；
- 前景压暗强度；
- 距离对比度衰减；
- 前景偏色和后景偏色；
- 选择描边颜色和宽度。

这些参数同时在 `project.godot` 中注册为全局着色器变量，使图层滤镜和选择描边能够直接共享，不需要逐个材质传参。

`Renderer` 不再使用单独的场景或独立配置节点。`Layer_Controller_System._ready()` 在完成关卡节点发现后调用：

```gdscript
Renderer.apply_settings()
```

这样只有挂载图层控制系统的关卡场景才会执行渲染参数初始化，非关卡场景无需依赖特定节点结构。

滤镜参数已经从 `Level.gd` 移除。`Level` 继续只保存层数、缩放倍率和初始关卡层位置，关卡结构与渲染风格的职责由此分离。

## 四、相关系统清理

### 1. 删除旧 Line2D 结构

以下物体场景中的选择 `Line2D` 已删除：

- `Box`；
- `Goal`；
- `Platform`；
- `PlayerObject`；
- `ShadowedGeometry`。

对应子类中的 `selected_box`、`_outline` 和 `set_pick_condition()` 重复实现也一并删除。

### 2. 影子切割碎片适配

影子布尔系统生成新碎片时不再查找或更新 `VisualRoot/Line2D`。碎片只需要同步实体碰撞多边形、视觉多边形、点选碰撞多边形和影子模板，进入场景树后由 `LayerObject` 自动创建选择描边。

### 3. 鹰眼材质兼容

鹰眼递归现在同时识别 `Polygon2D` 和 `Sprite2D`。选择描边副本带有专用元数据标记，鹰眼刷新时会跳过这些节点，避免覆盖描边材质。

### 4. 重叠对象选择顺序

普通物体的 Z 轴已经统一交给 `DepthLayer CanvasGroup` 管理，点选系统不能再依赖 `Area2D.z_index` 判断前后关系。

当前点选逻辑会先从点击区域向上查找对应 `LayerObject`，再比较 `owner_layer.z_index`，优先选择画面中更靠前图层的物体。

## 七、当前边界与后续验证

1. 当前项目内的主要白模视觉仍是凸多边形。对于复杂凹多边形，顶点扩张后的轮廓需要结合正式素材继续观察。
2. `Sprite2D` 路径已经通过脚本与着色器编译，但当前项目缺少代表性的精灵资源；接入正式贴图后应重点验证透明边缘、图集帧和区域精灵。
3. 精灵描边采用 16 方向 Alpha 采样。当前只对选中物体启用，开销可控；如果未来支持大量对象同时高亮，需要重新评估采样数量。
4. 当前默认滤镜参数以白模可读性为目标，前景压暗、对比度衰减和偏色仍需结合正式背景色与美术素材继续调整。
5. 后景体积雾尚未重新接入，后续应作为独立效果设计，避免再次承担后景提亮与颜色分层等重复职责。

今天的更新将“整层空间表现”和“单个物体交互反馈”明确拆分：图层滤镜负责表现远近关系，选择描边只负责提示当前操作对象。两类效果共享全局参数，但拥有独立材质和渲染顺序，为后续正式美术资源接入保留了更清晰的扩展空间。
