# 黑夜关卡层照明

Level09～12 使用 `Game/NightLightSystem` 创建一盏带原生阴影的 PointLight2D。光源跟随 `Player/LightOrigin`，位于玩家根节点上方 85 单位，继承玩家移动、缩放及无人机状态变换，不跟随待机头部晃动。

默认照明强度较低，范围较大。2026-10-18 起仅保留关卡层实体表面的照明，移除全屏 NightAir 空气叠加，避免灯光在透明区域与背景混色。更换背景不改变实体照明，灯光开关也不改变背景显示。

## 参数

在 Level 根节点的“关卡层夜间照明”分组调整，运行时会同步到灯和材质：

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| `night_light_radius` | 1600 | 世界坐标中的照明半径；内部 70% 范围保持平缓，外围逐渐淡出 |
| `night_light_energy` | 0.28 | 原生 PointLight2D 光强 |
| `night_light_color` | 柔和暖白色 | 关卡层表面的光色 |
| `night_ambient` | 0.86 | 仅当前关卡层的无直射光亮度 |
| `night_surface_width` | 32 | 迎光表面的亮度向实体内部衰减距离 |

`NightLightSystem.enabled` 可在远程场景树中即时开关，用来对照原始亮度。`is_night` 在关卡载入时决定是否创建灯和遮光体；日间关卡不创建这些资源。

## 合成与遮挡

- PointLight2D 的光照及阴影掩码使用第 17 位，受光范围同时限制为主画布的 CanvasLayer 0、Z=0。只有关卡层的 DepthLayer 最终合成接收此光源，子物体、雾和跨层 ShadowVisual 不重复受光。
- 关卡层的图层材质根据景深计算响应。其他层保持原来的景深颜色；整层轮换后由新进入 Z=0 的图层接收灯光。
- 物体的 VisualRoot 下创建 LightOccluder2D，复用其碰撞多边形。仅当前关卡平面的遮光体启用；换层、碎片生成、轮廓变化和物体删除会自动同步。
- 表面 Shader 使用 LightOccluder2D 生成的 SDF，沿入射方向寻找迎光表面，计算表面朝向和进入实体的距离。光强、范围和其他物体的遮挡由 PointLight2D 的纹理及原生阴影图处理。阴影查询点移到表面外侧，避免物体内部被自身完全遮黑。
- 不创建全屏空气面，原来的 `night_air_opacity` 参数与 Night_Air Shader 已移除。透明区域直接显示后方内容，不再产生来自灯光的全屏明暗覆盖。
- 背景位于独立 CanvasLayer，界面同样在灯光范围之外；跨层影子继续保持纯黑。

此模块独立于现有影子管理；`shadow_box / shadow_visual / shadow_active`、成对节点生成、投影计算和静止两秒后的实体切割流程均未修改。

没有逐帧 CPU 多边形布尔运算、CPU 图像上传或纹理回读。轮廓不变时复用遮光多边形；表面内部较深的位置跳过 SDF 步进。

## 验证

```powershell
& "C:\Program Files\Godot\Godot_v4.7.2-stable_win64_console.exe" --path . res://tests/night_light_test.tscn --max-fps 60
```

使用真实 GPU 渲染器，不支持 `--headless`。窗口自动退出，截图和 JSON 输出至忽略的 `.godot/night_light_qa/`。需要取消限帧和垂直同步时使用 `--max-fps 0 --disable-vsync`。

- `01_level09.png`：原始 Level09 的照明结果，未调整保存的关卡布局。
- `02_surface_only.png`：在内存中隔离表面、遮挡和跨层黑影的对照场景。
- `03_lighting_disabled.png`：相同场景关闭夜间照明，用于比较原始亮度。
- `04_background_isolated.png`：更换三种背景贴图并对照灯光开关后的场景。
- `04_wide_range.png`：缩小视角，验证超过 1100 单位距离的实体表面仍能受光。
- `05_after_cycle.png`：整层轮换后的照明归属。
- `06_uav_resized.png`：无人机移动、缩放和窗口变化后的结果。
- `07_day.png`：正式转场回到日间关卡。

2026-10-18 在 Godot 4.7.2、D3D12 Mobile、RX 7650 GRE 上，51 项照明检查通过，包括三种背景的灯光开关像素对照、其他图层亮度、换层受光归属、超过 1100 单位的表面照明和跨层纯黑影子。照明同步 CPU P95 为 0.10 ms，原始 Level09 绘制调用数为 48。CPU 同步采样不包含 GPU 阴影图和 SDF 渲染成本，不代表其他设备的帧率保证。
