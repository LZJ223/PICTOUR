# 黑夜渲染回归测试

```powershell
& "C:\Program Files\Godot\Godot_v4.7.2-stable_win64_console.exe" --path . res://tests/night_render_test.tscn --max-fps 60
```

需要真实渲染器，不支持 `--headless`。窗口会自动打开并退出，返回码 0 表示所有断言通过。截图和报告输出到 `.godot/night_qa/`。

测试使用 Level09 的实际相机、图层和材质，并在内存中加入隔离探针；不会修改保存的关卡布置。随后通过正式转场覆盖 Level09～12、白天关卡和菜单。像素回读与性能采样只存在于此测试中。

`01` 为原布置截图；`01b` 暂时抬高一个真实投影箱，验证后方箱子的纯黑投影及遮罩关闭后的原色；`01c` 暂时隐藏前方地面，验证普通 Soil 接影。`02` 和 `02b` 验证表面距离衰减、空气明暗分界及物体遮光，并对照非关卡层的原亮度。

帧率会受到垂直同步和限帧等待影响。比较实际渲染开销时，将命令末尾改成 `--max-fps 0 --disable-vsync`；测试会自动等待物理落地判定，不依赖固定数量的渲染帧。
