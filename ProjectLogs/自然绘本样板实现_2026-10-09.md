# 自然绘本样板实现 · 2026-10-09

## 已确认的目标

用户批准重做样板，并澄清：规则应符合直觉，地平线可以是固定世界底面；同在背景中的树、石、拱门不能因美术实现不同而有的可搬、有的不可搬。当前实现继续在 `dev`，未暂存、提交或推送。

这次交付是一段约3000px、两层的可试玩庭园回路，用来验证人物尺度、自然景物组合、路线与书签恢复。完整序章播片、能力丢失叙事、7–10分钟内容与第一章大地图留待样板体验确认后继续。

## 入口与试玩

F5：`Natural_Garden_Game.tscn`。若编辑器仍保持此前入口，直接打开这个场景按F6。独立启动器沿用项目主场景。原 `Prologue_Test_Game.tscn` 与 `Prototype_Game.tscn` 保留作回归参照。

| 操作 | 输入 |
|---|---|
| 走、跑、短冲 | A/D；按住Shift跑，短按释放冲刺 |
| 跳跃 | Space；短松轻跳，按住满跳 |
| 景物换层 | 左键选择；W移近、S移远 |
| 记录书签 | 靠近凝墨圆印与红丝带，E |
| 恢复、地图 | R恢复最近书签；M展开、点击已发现书签，Esc收起 |
| 看干净画面 | F8隐藏教学和书签近距离提示，保留简短反馈 |

建议依次试玩：跨过开页折角石；到左岸缺口附近，将背景枯枝搬入并沿三折踏面往返；回纸岸书签恢复初始摆位，再搬入拱门登顶收墨、越岸并沿右阶走回；继续经回岸石、藏墨树去折枝庭，E记录，M在两书签间往返。失败坠落会被纸页接住，没有死亡惩罚。

路线没有指定对齐按钮或唯一角度，搬运保留当前屏幕轮廓。换站位会改变背景物件的位置关系；占用拒绝后可以换站位再试，或用书签恢复。路线验证中的约x800站位是自动化脚本的一组解法，不是关卡中强制吸附位置。

新组件 `Component/Player/Traveler_Large.tscn`：

| 项目 | 当前值 |
|---|---|
| 显示身高／碰撞 | 约90px／30×86px，脚锚0 |
| 走／跑／短冲 | 250／400／560px/s，短冲0.16s |
| 起跳／重力 | 610px/s／1800px/s² |
| 满跳／轻跳实测 | 108.574px／41.225px |
| 地面加速／刹停 | 2600／2800px/s² |
| 空中加速／减速 | 1400／500px/s² |
| 跳跃缓存／离地容错 | 各0.1s |

直身一体式工作服、肩袖和短手臂、约三分之一身高的细线双腿，避免旧版披风式轮廓。`Art/Player/V2/` 透明PNG图集含待机8帧、走跑各16帧及起跳、上升、下落、冲刺、落地、刹停、转身姿态；相位由实际速度推进，动作不锁输入。

围巾为独立8点、72px惯性丝带，响应运动、急刹和转身。跑动尾部波幅约22.4px；传送清历史。物理帧计算，渲染帧只做点插值重绘，不写角色或相机变换。旧玩家与控制器默认值保留，可变跳高默认关闭，仅新组件开启。

## 美术与景物规则

暖纸面、梅紫实体、浅鼠尾草背景、灰粉扇叶。红色集中于角色围巾与书签。自然地面直接作为纸页地平线，不再显示砖刻线路面；树、拱门与枝面本身承担落脚作用。

`Component/Object/Natural_Object/` 与 `Art/Nature/` 包含岩石、短树、空拱、枯枝和扇草五个素材家族，各两张透明PNG及对应SVG。四个实体家族与无实体植物共用换层逻辑。`kind / dimensions / variation / display_name` 可在关卡实例中调整，脚锚统一，名义轮廓与PNG来源对应。

- 拱门使用开底凹多边形，洞口为空；顶部和左右阶面可站立。拱脚仍是实体，洞内净空不意味着能够从外侧穿过柱子。需要跨沟、下层入口或另建落点。
- 树的踏面交错分布，减少头顶遮挡；枝面宽度按30px人物碰撞调整。扇叶属于点选轮廓，踏面以枝干平面为准。
- 花草可点选和换层，只有视觉／点选轮廓，不阻挡人物。没有把花草另做不可选的背景装饰。
- 悬停和选择显示墨线，失效位置用暖褐提示；没有普遍朱砂标签。材质景深改变外观，不改变物件身份。

系统优先使用自然物件的凸分块查询，真实空洞不会被大矩形填满；无实体植物显式允许搬运。旧单矩形／多边形回退保留。根节点保存世界位置，CollisionBox保存实体尺度，VisualRoot保存投影。换层前后点选轮廓角点误差验证小于0.02px。

底面 `Horizon_Terrain` 是明确的固定世界基础，不属于LayerObject。当前可玩关卡只两层；树、岩、拱门、枝、花草全部可搬，未使用不可搬的同类建筑贴图。相机固定Y=360，底面Y=600，背景贴地景物实体脚点Y=660；目前站位主要改变水平对齐，高低路线由景物各踏面与初始设计提供，尚未加入任意二维拖动。

## 母素材和来源

- 新角色、五家族景物：原创GDScript生成SVG，经Godot栅格化为PNG。生成器、原始SVG、PNG和帧资源均留在仓库，后续可改变同一父轮廓及纹理，减少每次重新生成整套素材的漂移。
- `Art/Materials/Dry_Ink_AI.png`：内置imagegen生成的干墨肌理，静态应用于地平线与景物表面。准确模型名未由工具提供，不标作已确认的image2.5。完整提示在 `Dry_Ink_AI.prompt.txt`，来源、日期和用途在 `Sources.json`；原始生成文件保留在Codex生成目录，项目使用工作区副本。
- 纸纹与墨滴沿用已有原创素材；风格参考为项目已接受的 `Art/Concepts/Paper_Garden_01.png`。没有将整张概念背景烘焙为不可搬建筑。

这是可编辑的风格化美术样板，尚非最终逐帧手绘稿。程序生成图形与AI表面纹理的审美效果，仍由人类通过试玩确认。

## 凝墨书签与磁盘进度

「纸岸」「折枝庭」使用凝墨圆印与红丝带为符号。初始纸岸自动记录；靠近E记录当前全场可搬景物布局，并发现该书签。M展示纸页示意地图，可选择已发现书签返回，展开时暂停玩家与背后交互。

`BookmarkManager` 按稳定物件ID记录固定layer_id、根位置、CollisionBox尺度。每枚书签有自己的完整摆位快照。R、坠落、地图返回和读档恢复对应布局，墨水、能力与已发现书签单独永久保留；默认存档为 `user://Natural_Garden_Save.json`。使用版本、内容校验与同目录临时写入后替换，坏数据不会执行任何指令或抹掉运行进度。

如果可搬实体围住书签，恢复按最新轮廓寻找附近完整身体可容纳的位置，不改已记录景物。本次复现了Godot同帧恢复后空间宽相位尚未更新的问题：对刚恢复的可搬物件直接按最新凸形状判断，空间查询排除它们，只检查未变固定地形。无需等待一帧或让角色先嵌进实体。

书签不是最终完整地图系统；当前纸页只呈现两个记录点，没有绘制全部场景或隐藏区域。跨版本物件改名需维护persistent_id／存档迁移，不能将设计场景改名当成无影响操作。
